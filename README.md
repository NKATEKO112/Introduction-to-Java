Welcome to my Java Programming Portfolio. This repository contains a collection of Java practice exercises completed during my first year of studies at Tshwane University of Technology (TUT) for the Principles of Programming A.

The exercises in this repository document my progression from basic algorithmic thinking (using Scratch) to writing fully functional, text-based Java applications. The code explores core programming concepts including variables, data types, user input/output, mathematical calculations, decision-making structures, and iteration (loops). While the themes of the exercises vary—from calculating store discounts to simulating dice games—they all demonstrate a strong foundation in algorithmic problem-solving.

🛠️ Core Skills Demonstrated
Throughout these units, I applied the following technical skills:

Java Environment: Compiling and running .java files via the Command Prompt, understanding the Java Virtual Machine (JVM), and identifying syntax, runtime, and logical errors.

Data Types & Variables: Declaring and initializing primitive data types (int, double, char, boolean), using String objects, and declaring final constants.

Input & Output: Reading user data via the Scanner class, and displaying formatted output using System.out.println(), escape sequences (\n, \t), and the DecimalFormat class.

Mathematical Operations: Utilizing order of precedence, integer division, the modulus operator (%), and methods from the Math class (e.g., Math.pow, Math.sqrt, Math.random).

Type Casting: Understanding widening (automatic) and narrowing (explicit) conversions.

Decision Making: Using relational operators, Boolean logic (&&, ||, !), if, if-else, nested if-else, ternary operators, and switch statements.

Iteration (Loops): Implementing while, do-while, and for loops, including the ITC (Initialize, Test, Change) principle and nested loops.

String Manipulation: Comparing strings (equals, compareTo, equalsIgnoreCase), and converting text cases (toUpperCase, toLowerCase).

Algorithmic Planning: Translating pseudocode and flowcharts into functional Java code, and using trace tables to predict outputs.
